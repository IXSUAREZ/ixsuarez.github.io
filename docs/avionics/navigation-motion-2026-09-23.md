# Navigation and motion refinement

Release candidate implementation. Apple HIG was consulted on September 23, 2026; the result is a web adaptation, not a native Liquid Glass material or Apple conformance claim.

| Area | Apple source and decision | Implementation | Evidence / status |
| --- | --- | --- | --- |
| Navigation | [Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars): keep important destinations stable and labeled. The approved compact dock stays; Menu now contains every top-level site destination in two scannable groups. | Shared navigation partials and `sync-chrome.py` keep dock and menu current-page state in static HTML; `site-nav.js` marks Learn, Blog, and tool sections at runtime. | Synced 517 HTML pages; `sync-chrome.py --check` and focused navigation tests pass. Browser checked Home and Learn at 320px and desktop. |
| Material | [Materials](https://developer.apple.com/design/human-interface-guidelines/materials): put translucent material on navigation and temporary controls, with legible text over varied backdrops. The menu is more opaque than the dock; matte content stays unchanged. | `avionics.css` uses a semantic menu surface, preserves solid-control and reduced-transparency fallbacks. | Browser inspected open Menu in Dark and Day at 320px and Dark desktop. |
| Motion | [Motion](https://developer.apple.com/design/human-interface-guidelines/motion): make feedback short, meaningful, and interruptible. Keys and buttons react immediately; Menu fades and moves slightly; same-origin page changes crossfade without delaying navigation. | Shared CSS control states and cross-document View Transitions; browsers without support navigate normally. Reduced motion disables the transition. | Browser checked Menu, Home → Learn, browser Back, and reduced-motion computed styles. |
| Accessibility | [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility): preserve clear state, keyboard access, and motion alternatives. Closed Menu content is inert; open Menu supports Escape, outside dismissal, and focus return. | `site-nav.js` and shared CSS; native links and tool controls remain authoritative. | Navigation tests pass; 320px menu stays inside the viewport and scrolls to appearance controls. Physical Safari and VoiceOver remain unverified. |

The static audit originally reported five failures: a local review gallery was classified as a public page, the approved hero CTA icons differed from the old hero baseline, and two already-published UI changes differed from protected-source hashes. The audit now excludes the local gallery, permits only those exact UI bytes, and still compares the rest of the hero and protected sources. The release candidate reports zero failures. This refinement did not edit the homepage sky implementation or calculator logic.
