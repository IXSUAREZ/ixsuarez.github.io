# Private Flight Lesson Guide entry point

This public route contains only a gateway to the owner-authenticated private Worker. Course data, teaching runtime and PDFs are maintained and deployed from the separate private project on VIXIONDRIVE. No enrollment secret is present here.

The retirement service worker clears only `flight-lesson-guide-*` caches and unregisters. Protected responses on the private host are authenticated before asset delivery and use no-store caching.

Access control does not recall previous downloads or erase historical public Git revisions. Passkey enrollment must be completed by the owner on their device.
